✧ How do I use Content Studio?
  1. Choose a section in the left menu, then edit the text.
  2. Export JSON when it looks right. Your local draft alone does not change MAHA.
  3. Replace content/today.json in your private clone with the exported file, run npm test, and review before merging.

For a safe local preview, clone your private repository and run npm run dev. Nothing from this editor is uploaded automatically.
