# MAHA — A Little Escape

A handcrafted interactive world with letters, flowers, a cozy room, travel postcards, music, cinema, an arcade, and small moments worth keeping.

This is the **new home** for MAHA. This repository begins with a fresh history and does not reuse the previous project's Git commits or URLs.

## Website

Once the repository has been reviewed and made public, enable **Settings → Pages → Build and deployment → Deploy from a branch**, choosing **main** and **/(root)**.

The expected URL will be:

https://onetripteam-com.github.io/Maha-s-world/

Image source attribution: [CREDITS.md](CREDITS.md).

## Development

The project is a static website. Keep only one branch, **main**, for day-to-day development.

```bash
npm run dev
```

This starts a private local preview at http://127.0.0.1:4173/. The authoring workspace is at `/studio.html`.

```bash
npm test
```

Content Studio edits browser-local drafts and exports JSON; it does not automatically publish changes.

## Privacy

Everything committed to a **public** GitHub repository can be viewed, copied, and archived by anyone, even if the webpage hides or locks certain letters. Review all letters, names, images, file metadata, links, and content before making this repository public.

The former private repository remains unchanged and is not a deployment source.
